Кандидат: Долгов Евгений  
Дата подготовки: 27.07.2026

## 01 — Сбор базы

- `База_потенциальных_клиентов_POLZA.xlsx` — 50 уникальных B2B-компаний, контакты, официальные источники и персонализация.
- `База_потенциальных_клиентов_POLZA.csv` — тот же набор в UTF-8 CSV.
- `collect_public_contacts.py` — вспомогательный сборщик публичных адресов с официальных сайтов.

Важно: email подтверждены как опубликованные на официальных сайтах. SMTP-проверка и тестовые отправки не выполнялись, чтобы не создавать нежелательные сообщения.

## 02 — Персонализация

- `personalize_companies.py` — воспроизводимый скрипт: принимает XLSX/CSV, извлекает факт только с официального сайта, добавляет источник и статус проверки.
- `Результат_работы_скрипта.xlsx` — результат запуска на 50 строках.

## 03 — Цепочка писем

- `Цепочка_из_3_писем_POLZA.docx` — три письма: день 0, +3 дня, +5 дней.
- Та же цепочка находится отдельным листом в основной XLSX.

## 04 — База POLZA

- `Проверка_и_персонализация_15_компаний.xlsx` — 15 строк, персонализация, источники и отдельная проверка намеренно перепутанных полей.

## 05 — LLM-стек

- `ЗАПОЛНИТЬ_ЛИЧНО_LLM-стек.md` — структура и подтверждённые опорные факты из Obsidian.

Этот пункт нельзя сдавать без личной редакции: в исходном задании прямо указано «сам руками, без ИИ». Нужно дописать реальные подписки, суммы, личные критерии и примеры.
